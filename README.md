# 班級點餐系統

幫班級統一訂餐的網頁工具：選擇點餐的班級或學生、依分類點選餐點，自動整理出兩份清單。

- **店家總單**：跟店家點餐用，同樣的餐點會合併數量。
- **各班／個人帳單**：方便收錢，列出每個人點了什麼、要付多少。

打開 `index.html` 就能使用，不需要安裝。
